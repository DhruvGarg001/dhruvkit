# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-02-17

### Added
- Initial release of DhruvKit
- Beautiful CLI interface with Rich terminal output
- Smart templates system (Basic, FastAPI, Flask)
- Modular add-on system for templates
- FastAPI template with MongoDB, Firebase, and Security add-ons
- Generates projects with multiple license options (MIT, Apache, GPL, BSD, Unlicense, CC0)
- `new` command - Create new projects in new folders
- `init` command - Initialize projects in current directory
- `add` command - Add licenses to existing projects
- `docs` command - Interactive documentation viewer
- Short command alias `dk` as alternative to `dhruvkit`
- Short option `-t` as alternative to `--template`
- Optional dependencies installation support via pip extras
- Intelligent file merging for multiple add-ons
- Automatic README generation with usage guides
- Environment variable management with .env files
- Comprehensive security middleware for FastAPI projects
- Firebase Admin SDK integration
- MongoDB Atlas connection management

### Documentation
- Added installation instructions with optional dependencies
- Added quick start guide
- Added template documentation
- Added add-on system documentation
- Added author LinkedIn profile
